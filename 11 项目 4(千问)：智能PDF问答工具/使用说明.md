# 智能PDF问答工具（通义千问版）- 使用说明

## 📋 项目简介

这是一个基于通义千问大模型的智能PDF问答工具，可以上传 PDF 文档并与文档内容进行对话。利用 AI 技术实现文档内容的智能检索和问答。

## 🔧 环境要求

- Python 3.8 或更高版本
- 阿里云百炼 API Key（通义千问）

## 📦 安装步骤

### 1. 创建虚拟环境（推荐）

```bash
# 进入项目目录
cd "D:\software\python\Large_AI_model\11 项目 4：智能PDF问答工具"

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（PowerShell）
.\venv\Scripts\Activate.ps1

# 或者使用命令提示符
.\venv\Scripts\activate.bat
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

需要在系统环境变量中设置 `DASHSCOPE_API_KEY`：

**Windows PowerShell:**
```powershell
$env:DASHSCOPE_API_KEY="your_api_key_here"
```

**永久设置（推荐）：**
1. 右键点击"此电脑" -> "属性"
2. 选择"高级系统设置"
3. 点击"环境变量"
4. 在"系统变量"中新建：
   - 变量名：`DASHSCOPE_API_KEY`
   - 变量值：你的阿里云百炼 API Key

## 🚀 获取 API Key

1. 访问阿里云百炼平台：https://help.aliyun.com/model-studio/
2. 注册/登录阿里云账号
3. 开通百炼服务
4. 创建 API Key
5. 复制并保存您的 API Key

## ▶️ 运行程序

```bash
# 确保已激活虚拟环境并配置好环境变量
streamlit run main.py
```

程序会在浏览器中自动打开，默认地址为：http://localhost:8501

## 💡 使用指南

1. **上传 PDF 文件**
   - 点击侧边栏的"上传 PDF 文件"按钮
   - 选择您要问答的 PDF 文档
   - 等待系统处理完成

2. **开始问答**
   - 在底部输入框中输入您的问题
   - AI 会根据 PDF 内容给出答案
   - 可以查看参考来源

3. **调整参数**（可选）
   - **模型选择**: qwen-turbo（快速）、qwen-plus（平衡）、qwen-max（最强）
   - **Temperature**: 控制回答的创造性（0-1）
   - **Max Tokens**: 控制回答长度
   - **文本分块大小**: 影响检索精度
   - **文本分块重叠**: 提高上下文连贯性

## ⚙️ 配置说明

### 模型对比

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| qwen-turbo | 速度快，成本低 | 简单问题、快速响应 |
| qwen-plus | 性能均衡 | 大多数场景 |
| qwen-max | 能力最强，成本高 | 复杂问题、专业领域 |

### 参数调优建议

- **Temperature**: 
  - 事实性问题：0.3-0.5
  - 创意性问题：0.7-0.9
  
- **文本分块大小**:
  - 技术文档：300-500
  - 学术论文：500-800
  - 一般文档：400-600

## 🔍 技术原理

1. **文档加载**: 使用 PyPDFLoader 读取 PDF 内容
2. **文本分割**: 将长文档切分成合适的小块
3. **向量化**: 使用 OpenAI Embeddings 将文本转换为向量
4. **存储索引**: 使用 FAISS 建立向量索引
5. **检索**: 根据问题检索最相关的文档片段
6. **生成答案**: 调用通义千问 API 生成答案

## ❗ 常见问题

### Q1: 提示"未找到环境变量 DASHSCOPE_API_KEY"
**解决方法**: 按照上述步骤 3 配置环境变量，重启终端或 IDE

### Q2: 安装依赖时出错
**解决方法**: 
- 确保使用 Python 3.8+
- 尝试升级 pip：`pip install --upgrade pip`
- 检查网络连接

### Q3: PDF 上传后处理很慢
**解决方法**:
- 减小"文本分块大小"参数
- 使用更小的 PDF 文件测试
- 检查电脑内存是否充足

### Q4: 回答质量不高
**解决方法**:
- 切换到 qwen-max 模型
- 调整 Temperature 参数（降低随机性）
- 确保问题表述清晰具体

## 📝 注意事项

1. 首次运行会自动下载必要的模型文件，请保持网络连接
2. 大型 PDF 文件处理时间较长，请耐心等待
3. 临时文件会自动清理，但建议定期手动清理 temp_开头的文件
4. 本工具仅支持文字型 PDF，扫描件可能无法识别
